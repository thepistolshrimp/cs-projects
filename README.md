# Computational Science Projects

A collection of programming and numerical modelling projects completed during my B.Sc at UiO.

## Projects

### [Game of Life](game-of-life-java/)
Java implementation of Conway's Game of Life using object-oriented programming, a two-dimensional grid, neighbour tracking, and generation updates.

### [Concurrent Frequency Analysis](concurrent-frequency-analysis-java/)
Java project using threads, monitors, locks, and frequency tables to read and merge subsequence data concurrently.

### [SEIR Disease Model](seir-disease-model-python/)
Python implementation of an extended SEIR-type epidemic model, including time-dependent transmission rates, outbreak scenarios, lockdown data, and imported infections.

### [Double Pendulum](double-pendulum-python/)
Numerical modelling of a double pendulum, including a small-angle approximation, analytical normal modes, Euler-Cromer integration, and nonlinear simulations.

**Six Degrees of IMDb** Python compulsary-assignment using BFS, DFS and Dijkstra's algorithm to analyse connections between actors and movies.
